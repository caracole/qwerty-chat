📨 Secret Messages

Simple guide — read on your phone
How does it work?
You receive a strange message on WhatsApp.
You paste it into the app.
The app shows you the real message.
1
Open the app file
Find the file on your phone called
cifrador_qwerty.html

Tap it. It opens in your browser (like a web page).
💡 If you can't find the file, ask your contact to send it to you via WhatsApp.
2
You receive a secret message on WhatsApp
The message looks like this — that's normal, it's encrypted code:
3a7f2c9b1e4d8a6f2c9b1e4d8a6f3a7f2c9b...
⬇
Press and hold on it, then tap Copy.
3
Paste the code into the app
In the app, you'll see a large box at the top right labelled
"Código cifrado".

Press and hold inside it, then tap Paste.
Don't forget to enter the secret key in the 🔑 field.
This is the word you chose together.
4
Tap "Descifrar" to read
Tap the big green button ⬡ Descifrar.

The real message appears below:
⬇
Hello! How are you doing today?
⚠️ The secret key
You and your contact must use exactly the same secret word.

For example: sunshine or London1940

Agree on it together by phone call, never by written message.
5
To reply, use the other side
To send a secret message in return:

1. Go to the "Texto original" box (on the left)
2. Type your message
3. Enter the secret key 🔑
4. Copy the code that appears
5. Send it via WhatsApp
✅ The ⎘ Copiar button copies the code automatically.
In summary
📩 You receive a code via WhatsApp
⬇
📋 You paste it into the app
⬇
🔑 You enter the secret word
⬇
✅ You read the real message
