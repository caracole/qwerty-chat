📱 Installer QWERTY Chat

sur ton téléphone Android — sans passer par le Play Store
1Mettre les fichiers en ligne
Tu dois d'abord mettre les 3 fichiers sur internet. La façon la plus simple : GitHub Pages (gratuit).
📂 Les 3 fichiers à mettre ensemble :
• cifrador_qwerty.html
• manifest.json
• icon.png
2Aller sur GitHub Pages
1. Va sur github.com et crée un compte gratuit
2. Crée un nouveau "repository" (dossier en ligne)
3. Appelle-le : qwerty-chat
4. Upload les 3 fichiers
5. Active "GitHub Pages" dans les réglages

Ton app sera disponible à cette adresse :
https://TON-NOM.github.io/qwerty-chat/cifrador_qwerty.html
3Ouvrir l'adresse sur ton téléphone
Sur ton téléphone Android, ouvre Chrome et tape l'adresse de l'étape 2.
Envoie l'adresse par WhatsApp à toi-même pour ne pas avoir à la taper !
4Ajouter à l'écran d'accueil
Dans Chrome, appuie sur les 3 points en haut à droite.

⋮
Puis appuie sur :

📲 "Ajouter à l'écran d'accueil"
Appuie sur Ajouter.

C'est terminé ! L'app apparaît sur ton écran comme une vraie application.
✅ Résultat
Tu as une icône sur ton écran d'accueil.
Tu appuies dessus — l'app s'ouvre sans navigateur, comme une vraie application.
Ça fonctionne même sans connexion internet !
💡 Alternative encore plus simple
Si GitHub te semble compliqué, envoie les fichiers à quelqu'un qui peut les mettre en ligne pour toi (un petit-fils, un ami...). C'est 5 minutes de travail pour quelqu'un qui connaît.
