📨 Messages secrets

Guide simple — à lire sur téléphone
Comment ça marche ?
Tu reçois un message bizarre par WhatsApp.
Tu le colles dans l'application.
L'application te montre le vrai message.
1
Ouvre le fichier de l'application
Cherche sur ton téléphone le fichier qui s'appelle
cifrador_qwerty.html

Appuie dessus. Il s'ouvre dans ton navigateur (comme une page web).
💡 Si tu ne trouves pas le fichier, demande à ton proche de te l'envoyer par WhatsApp.
2
Tu reçois un message secret par WhatsApp
Le message ressemble à ça — c'est normal, c'est du code chiffré :
3a7f2c9b1e4d8a6f2c9b1e4d8a6f3a7f2c9b...
⬇
Appuie dessus, maintiens le doigt, puis appuie sur Copier.
3
Colle le code dans l'application
Dans l'application, tu vois une grande case en haut à droite qui dit
"Código cifrado".

Appuie dedans, maintiens le doigt, puis Coller.
N'oublie pas d'entrer la clé secrète dans le champ 🔑
C'est le mot que vous avez choisi ensemble.
4
Appuie sur "Descifrar" pour lire
Appuie sur le grand bouton vert ⬡ Descifrar.

Le vrai message apparaît en dessous :
⬇
Bonjour ! Comment vas-tu aujourd'hui ?
⚠️ La clé secrète
Toi et ton proche devez utiliser exactement le même mot secret.

Par exemple : soleil ou Paris1940

Decidez-le ensemble par téléphone, jamais par message écrit.
5
Pour répondre, c'est l'autre côté
Pour envoyer un message secret à ton tour :

1. Va dans la case "Texto original" (à gauche)
2. Écris ton message
3. Entre la clé secrète 🔑
4. Copie le code qui apparaît
5. Envoie-le par WhatsApp
✅ Le bouton ⎘ Copiar copie le code automatiquement.
En résumé
📩 Tu reçois un code par WhatsApp
⬇
📋 Tu le colles dans l'application
⬇
🔑 Tu entres le mot secret
⬇
✅ Tu lis le vrai message
